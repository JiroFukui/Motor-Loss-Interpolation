# モータ損失データ補間アプリ

異なる刻み方のモータに対して損失データを2次元補間するWebアプリケーションです。

## 機能

- **元データのアップロード**: CSV形式のモータ損失データを読み込み
- **新しいグリッドの設定**: 回転数とトルクの新しい刻み方を指定
- **2次元補間**: 線形補間または3次スプライン補間を選択可能
- **可視化**: ヒートマップと3Dサーフェスプロットで結果を表示
- **結果のダウンロード**: 補間後のデータをCSVファイルとしてエクスポート

## Windows環境での使用方法（推奨）

### 初回セットアップ
1. **setup.bat** をダブルクリック
2. 自動的に仮想環境が作成され、必要なパッケージがインストールされます

### アプリの起動
1. **run.bat** をダブルクリック
2. 自動的にブラウザが開き、アプリが表示されます

詳しくは **使い方.txt** を参照してください。

## コマンドラインでの使用方法

### インストール

```bash
pip install -r requirements.txt
```

### 起動

```bash
streamlit run app.py
```

ブラウザで表示されたURLにアクセス（通常は http://localhost:8501）

3. CSVファイルをアップロード:
   - 1列目: 回転数 [rpm]
   - 2列目: トルク [Nm]
   - 3列目: 損失 [Wh]

4. 新しいモータのグリッドを設定:
   - 回転数の範囲と刻み幅、またはカンマ区切りで個別指定
   - トルクの範囲と刻み幅、またはカンマ区切りで個別指定

5. 補間方法を選択して実行

6. 結果を確認してCSVファイルとしてダウンロード

## 対応ファイル形式

- **CSV** (.csv)
- **Excel** (.xlsx, .xls)

## 対応データ形式

### 1. リスト形式（3列）
最も一般的な形式。回転数、トルク、損失を1行ずつ記載。

```csv
回転数_rpm,トルク_Nm,損失_Wh
1000,10,5.2
1000,20,8.5
1000,30,12.3
2000,10,6.1
2000,20,9.8
2000,30,14.2
3000,10,7.3
3000,20,11.2
3000,30,16.5
```

### 2. マトリックス形式（損失マップ）
縦軸にトルク、横軸に回転数を配置し、セルに損失値を記載。

```
トルク[Nm],500,1000,1500,2000,2500,3000
5,2.1,2.8,3.6,4.5,5.5,6.6
10,3.5,4.8,6.2,7.8,9.5,11.4
15,5.2,7.2,9.3,11.6,14.2,17.0
20,7.1,9.9,12.8,15.9,19.4,23.3
25,9.3,13.1,16.9,21.0,25.6,30.7
```

Excelファイルの場合も同様。複数シートがある場合はアプリ内でシート選択可能。

## 補間方法

- **線形補間 (linear)**: 高速で単純な補間。データが滑らかな場合に適用
- **3次スプライン補間 (cubic)**: より滑らかな曲線を生成。精度重視の場合に推奨
